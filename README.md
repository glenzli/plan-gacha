# 行程扭蛋

一个旅行中用来快速切换当天计划的小页面。它把计划池、每日安排、天气约束、互斥关系和 AI JSON 导入放在同一个本地页面里，数据默认保存在浏览器 `localStorage`。

## 功能

- 按日期查看行程，给每天切换一个主计划
- 每个计划支持必去、想去、备用、可放弃优先级
- 每个计划支持可去日期、闭馆/不可用日期、时间窗口、体力强度
- 天气规则支持很适合、可安排、不太适合三类条件
- 选择计划前预览会清空的冲突日期和后续风险
- 打开页面后自动使用 Open-Meteo 按计划地点查询天气，也支持按天手动修正
- 默认内置一组连续 5 天的青岛 sample 行程和若干 backup plan
- 复制当天上下文给 AI，导入 AI 返回的计划 JSON
- 下载和恢复本地备份

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash

```
