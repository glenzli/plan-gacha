# UI、流程与集成走查（2026-09-30）

本次保持现有产品样式与纯前端架构，覆盖旅行创建、候选安排、旅途编辑、住宿、清单、AI/JSON、旅行记录、归档、持久化和可选同步。浏览器使用生产构建与独立的公开示例数据；没有调用付费模型或向外部服务发送私人行程。

## 修复

- 旅行下拉框与触发按钮同宽、同起点；长列表在视口内滚动。支持方向键、Home/End、Enter、Escape、Tab、外部点击和焦点离开。更多操作与路线菜单可关闭，移动端不会越出视口。
- 共用弹窗焦点管理：背景不可交互、锁定背景滚动、Tab/Shift+Tab 留在当前最上层弹窗、Escape 按层关闭、返回触发按钮。补齐对话框名称、动态反馈、选项卡键盘操作与焦点样式。
- 改善文字对比、320px 布局、44px 主要触控按钮和移动端表单字号；尊重减少动画设置。移动端天气失败也可看到提示并重试。
- AI 问题及结果草稿在关闭、折叠、切换编辑面板后保留；切换旅行和成功应用后清理。未应用草稿触发浏览器离开提醒。
- 明确 AI 的日期、历史冻结、移动时清空旧日期、住宿独立调整、未知天气和警告输出约定。重新排程仅接受安排及住宿，不允许改写计划或旅行范围；预览依据变化后必须重新确认。
- 导入拒绝不可能日期、超出 1–30 天的时长、不支持的版本、空安排、重复日期/计划/活动安排。保留显式清空旧日期；缩小日期范围会预览/确认移除的安排，取消不会修改数据。
- localStorage 被禁用或配额不足时不再崩溃，并提示导出备份。损坏或未来版本旅行数据先保留原始字节；备份保存失败时保留原存储，恢复备份可单独导出并在刷新后继续访问。
- 同步操作增加同步忙碌锁，防止快速重复连接、创建、上传或自动同步；校验远端快照版本与结构，避免无效远端覆盖本地。

## dev-site 交接

源码目录为 `/workspace/plan-gacha`，生产输出为 `dist/`。dev-site 的 `scripts/sync-embedded-projects.mjs plan-gacha` 会复制构建、重写资源与 webmanifest 路径、同步封面/图标并更新内容同步清单；应用目标是 `public/apps/plan-gacha/app`，公开入口为 `/apps/plan-gacha/`。

```bash
# plan-gacha 更新到本次发布提交后
npm ci
npm run build

# 在 dev-site 根目录，同步该 executor 下的构建
PROJECTS_ROOT=/workspace node scripts/sync-embedded-projects.mjs plan-gacha
node scripts/check-content-sync.mjs --projects plan-gacha
```

注意：`PROJECTS_ROOT` 仅影响构建复制源；当前 dev-site 的 `scripts/project-sync-config.mjs` 仍把清单源路径写为 `~/lab/plan-gacha`。父线程应在其执行环境按已有惯例准备此源码路径或修正配置后再更新/检查清单，避免空源清单。本任务未修改 dev-site；同步、站点提交、所有远端推送和部署由父线程另行完成。
